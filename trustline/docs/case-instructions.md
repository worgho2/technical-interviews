Welcome! Thank you for participating in our technical case for the Junior/Mid-Level Engineer position. This case aims to evaluate your ability to interpret a technical specification, implement a functional API, and demonstrate development best practices.

## Your task

Use Java (Micronaut or Spring Boot) to develop a Consents API based on the provided specification (`consentsAPI.yaml`). Your API should be able to:

- Create consents, returning an initial status of `AWAITING_AUTHORISATION`.
- Retrieve the details for a specific consent.
- Update consent details, such as changing the status to `AUTHORISED`.
- Revoke consents by deleting them.

Ensure your API adheres to RESTful principles and responds with appropriate HTTP status codes. Do not modify the provided Swagger file (`consentsAPI.yaml`).

- Include a README file with relevant setup instructions and usage details.
- Include a quick video explaining your thought process.

- Automated tests to validate the API functionality.
